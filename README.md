Bayou Dawn is a Louisiana swamp-town open-world crime game at dawn: Cole runs Mama Odette's four-job airboat run across misty black water, stilt houses and back roads, by car and airboat, outrunning the police.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
